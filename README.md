# ⚛️ React Sales KPI Dashboard

[![React](https://img.shields.io/badge/React-18-61DAFB?logo=react&logoColor=black)](https://react.dev/)
[![JavaScript](https://img.shields.io/badge/JavaScript-ES2024-F7DF1E?logo=javascript&logoColor=black)](https://developer.mozilla.org/en-US/docs/Web/JavaScript)

An interactive, filterable Business Intelligence dashboard built with **React 18** that renders live KPI summary cards, dynamic filtering controls, and a transaction ledger with profit margin health indicators.

---

## 📌 Business Problem
Static Power BI dashboards require IT-managed licenses and cannot be embedded in web applications. This React dashboard delivers the same executive KPI visibility — total revenue, blended profit margin, average order value, and status badges — as a lightweight web component that any browser can render.

## ⚛️ React Concepts Demonstrated
- **Functional Components**: `KPICard`, `StatusBadge`, `App` as modular, reusable components
- **useState Hook**: Interactive category and region filter state management
- **useMemo Hook**: Performance-optimized filtered dataset recomputation
- **Props**: Typed component interfaces for value and styling
- **Conditional Rendering**: Dynamic color coding and status badge logic

## 🚀 Run It (Zero Install)
```bash
# Simply open the file in your browser — no npm, no build tools
start index.html   # Windows
open  index.html   # Mac
```
